# Entrena tu mente — sitio web de consultorio de psicología

Sitio web que desarrollé para un consultorio de psicología en Paraguay: presentación del equipo, tests de autoevaluación, testimonios y agendamiento de turnos en línea.

🔗 **Demo:** https://aaronacostaamarillo98-blip.github.io/entrena-tu-mente-web/

> Versión de portafolio: la agenda funciona en modo demostración (no guarda citas) y no incluye datos de pacientes.

## Funcionalidades
- Agenda de turnos con horarios, bloqueos, anticipación mínima y cancelación de citas.
- Perfiles de profesionales y tests de autoevaluación.
- Páginas de privacidad y términos; diseño responsive.

## Tecnología
HTML, CSS y JavaScript sin frameworks. Configuración en archivos de datos (`data/`), preparado para Cloudflare Pages. Desarrollado con asistencia de IA (Claude).
